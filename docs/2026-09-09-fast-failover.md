## Изменения

- Минимальный порог снижен с 30 до 15 секунд; интервал supervisor подстраивается под порог. Обновлены подсказки UI.
- Активный туннель проверяется HTTPS-запросом с привязкой сокета к интерфейсу и fwmark. Достаточно ответа одного из двух независимых адресов: `1.1.1.1`, `8.8.8.8`. DNS и прямой обход туннеля для этой проверки не используются.
- Резерв проверяется временным процессом sing-box с SOCKS только на loopback, без изменения маршрутов. Процесс завершается и собирается после проверки. Результат кэшируется на 15 секунд; повторная проверка активного туннеля в одном цикле кэшируется на секунду.
- Текущий и предпочтительный сервер проверяются параллельно. Исправный резерв сохраняется; автоматический возврат на основной требует периода восстановления и успешных проверок через VPN.
- Автоматическое применение использует сохранённые данные подписки. Исправлен старый баг удаления `source-cache-*.json` при очистке runtime.
- Для неизменного списка доменов одного провайдера и строго одного старого/нового runtime переносится ipset с оставшимися TTL. Переключение не делает повторные DNS-запросы для каждого домена. При отсутствии снимка, изменении доменов или неоднозначном соответствии используется обычное заполнение DNS.
- Отмена routing-команды завершает её группу процессов, чтобы дочерние команды не продолжали менять маршруты.
- Supervisor читает сокращённый runtime snapshot без подсчёта доменов и построения данных панели.
